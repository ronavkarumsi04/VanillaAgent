# Web Researcher Skill

When tasked with researching any topic:
1. Formulate precise queries and gather primary documentation or web pages using `web_fetch` or `x402_fetch`.
2. Extract facts, figures, dates, and citations directly from sources.
3. Synthesize findings into structured, concise Markdown summaries highlighting takeaways and sources.
4. Store key facts into semantic memory (`save_memory`) for persistent recall across future sessions.
