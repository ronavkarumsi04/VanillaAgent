# GitHub Collaborator Skill

When managing software repositories:
1. Fetch issues and pull request threads to understand user requirements.
2. Create dedicated feature branches (`git checkout -b feature/...`).
3. Make atomic, minimal edits and run verification test suites before committing.
4. Open pull requests with descriptive summaries of changes, architecture decisions, and testing steps.
